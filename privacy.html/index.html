Oddly True · Privacy

Privacy Policy

Last updated: 28 September 2026

The Oddly True publishing pipeline is a personal automation tool run by one person. It publishes that person's own videos to their own YouTube, TikTok and Instagram accounts. It has no sign-ups and no other users.

What it accesses

  • YouTube Data API — to upload the owner's videos, captions, thumbnails and playlists, and to read and reply to public comments on the owner's own videos.
  • YouTube Analytics API — aggregate statistics for the owner's channel (views, watch time, retention). These reports contain no information about individual viewers.
  • TikTok and Instagram — OAuth tokens for the owner's own accounts, used only to publish the owner's videos.

Viewer comments

To answer viewers, the pipeline reads public comments on the channel's own videos (the commenter's public display name and comment text) and forwards new ones to the owner as a private notification. It stores only the comment's ID, so that the same comment is not shown twice. Names and comment text are not stored, analysed, or shared.

What it never does

  • It does not sell, rent, share or transfer any data.
  • It does not use Google user data for advertising, profiling or training AI models.
  • These pages set no cookies and run no analytics or tracking. The console page loads its fonts from Google Fonts, which receives your IP address as part of the request.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Where it is kept

Access tokens are stored as encrypted secrets in a private GitHub repository and on the owner's own computer. They are used only to publish the owner's content.

YouTube and Google

This tool uses YouTube API Services. By interacting with it you are also bound by the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy. Access granted to this tool can be revoked at any time at Google security settings.

Contact and deletion

To ask about or request deletion of any data, contact the owner through GitHub.
